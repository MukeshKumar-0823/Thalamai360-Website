# Thalaimai 360 — தலைமை 360

> **Tamil Nadu's Premier Political Governance & Constituency Management Consultancy**

A cinematic, premium single-page website featuring a **realistic 3D gate opening animation** using the Tamil Nadu Secretariat building, built entirely with HTML, CSS, and vanilla JavaScript (Three.js + GSAP).

---

## ✨ Features

- 🏛️ **Realistic Gate Opening** — Tamil Nadu Secretariat building split across two 3D hinge doors; click to open
- 💡 **Light Burst Effect** — white flash as the gates crack open
- ✨ **WebGL Particle Canvas** — 1,000 floating brand-color particles (Three.js)
- 🔤 **Bilingual Typography** — Tamil (Noto Sans Tamil) + English (Cinzel serif)
- 📊 **Animated Stats Counters** — scroll-triggered number counters
- 🃏 **3D Tilt Cards** — 12 governance pillars with mouse-tilt perspective effect
- 📅 **Interactive Methodology Timeline** — 5-step transformation model
- 📝 **Consultation Form** — with validation and success feedback
- 📱 **Fully Responsive** — mobile-friendly layout

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | Vanilla CSS3 (custom design system) |
| 3D Engine | Three.js (WebGL particles) |
| Animations | GSAP 3 + CSS 3D transforms |
| Icons | Lucide Icons |
| Fonts | Google Fonts (Cinzel, Noto Sans Tamil, Outfit) |
